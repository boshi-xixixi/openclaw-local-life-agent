### 0.1 启动沙盒与验证

```bash
# 1. 启动沙盒
cd sandbox
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8900 --reload &

# 2. 验证沙盒存活
curl -s http://localhost:8900/ | python -m json.tool
# 预期: 返回 name/version/description/endpoints

curl -s http://localhost:8900/api/queue/R13 | python -m json.tool
# 预期: 返回 restaurant_id/queue_count/estimated_wait_min 等

# 3. 验证动态性
for i in 1 2 3; do
  curl -s http://localhost:8900/api/queue/R13 | grep queue_count
  sleep 5
done
# 预期: 至少看到一次 queue_count 变化
```

| 1 | 任意推荐场景 | 口语化，不像客服；用"好嘞""我帮你定" |
| 2 | 用户说"随便" | 帮做决定；明确推荐 + 理由；不给更多选项 |

## 八、问题排查手册

### 8.1 Skill 未被触发

| 症状 | 排查步骤 |
|------|---------|
| 提问"今天中午吃什么"无回复 | ① 确认 OpenClaw 网关运行 → ② 确认 skill 软链接 → ③ 查看 OpenClaw 日志 |
| 触发了错误的 Skill | ① 检查 SKILL.md 的 description 是否准确 → ② 检查 `metadata.requires` |
| 部分 Skill 可用，部分不可用 | ① 逐个检查 SKILL.md 语法（YAML frontmatter 是否合法） |

### 8.2 沙盒相关

| 症状 | 排查步骤 |
|------|---------|
| 沙盒 502 | `lsof -i :8900` 查端口占用 |
| 沙盒超时 | 检查 `uvicorn` 进程是否存活 |
| 排队数据不变化 | 检查 `RestaurantState` 初始化是否执行 |
| 事件不随机 | 检查 `random` 模块调用是否正常 |

### 8.3 脚本相关

| 症状 | 排查步骤 |
|------|---------|
| `node: command not found` | 安装 Node.js ≥ 16 |
| 脚本找不到 JSON | 检查相对路径；`cd` 到正确目录 |
| 脚本权限拒绝 | `chmod +x scripts/*.js` |

### 8.4 LLM 相关

| 症状 | 排查步骤 |
|------|---------|
| 推理慢 / 超时 | ① 检查模型 API 网络 → ② 减少上下文长度 → ③ 切换到更快模型 |
| 幻觉（推荐不存在的餐厅） | ① 确认 city-map.json 加载正确 → ② 在 SKILL.md 强调"禁止编造" |
| 对话风格跑偏 | ① 确认 SOUL.md 已加载 → ② 检查 temperature 设置（建议 0.7） |

### 8.5 跨 Skill 不联动

| 症状 | 排查步骤 |
|------|---------|
| 天气不传给下游 Skill | ① 在 life-service-query 的 SKILL.md 强调编排流程 |
| 偏好不被应用 | ① 确认偏好文件已写入 → ② 确认 LLM 读到了偏好内容 |
| 预算不统一分配 | ① 检查 SKILL.md 是否包含"预算分配"段落 |

## 数据源

使用 Read 工具读取 `references/deals-data.json`，包含：
- 餐厅优惠：满减/折扣/套餐/新人优惠
- 出行优惠：打车券/地铁月卡/共享单车月卡

使用 Read 工具读取 `../shared/city-map.json` 获取关联数据。

## Cross-Skill 联动规则

### 1. ← 餐饮联动
- 餐饮Skill推荐餐厅时，查询该餐厅的优惠信息一并展示
- 计算优惠后的实际花费

### 2. ← 出行联动
- 出行Skill推荐交通方式时，查询对应的打车券/地铁优惠
- 对比优惠后的实际成本

### 3. ← 娱乐联动
- 娱乐Skill推荐场所时，查询团购/早鸟/联票优惠
- 多场所推荐时，优先推荐有联票优惠的组合

### 4. ← 编排联动
- 编排中枢制定方案时，自动调用本Skill计算总优惠
- 展示"原价 vs 优惠后"的对比
- 当预算紧张时，主动建议使用优惠方案替代

### 5. → 预算优化
- 当用户预算紧张时，主动推荐优惠方案帮助降级成本
- 如"原方案总价700超预算100，使用联票后仅需580，省了120"

## 兜底策略

**当找不到优惠或预算仍无法满足时：**

| 优先级 | 策略 | 示例 |
|---------|------|------|
| 1 | 推荐替代优惠 | 没有联票 → 分别查单店优惠 |
| 2 | 建议调整方案 | 优惠后仍超预算 → 建议替换某个环节 |
| 3 | 免费替代 | 预算极紧张 → 推荐免费场所（公园等） |
| 4 | 明说无优惠 | 确实没有优惠时明说，但给出“原价也很值”的理由 |

**禁忌**：不要硬凑优惠数据，没有就说没有，但要给替代建议。

## 数据安全声明

本技能不收集任何真实用户个人信息。所有优惠数据为模拟数据，不接入真实优惠平台API。
